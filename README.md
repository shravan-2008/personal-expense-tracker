# Personal Expense Tracker

A beginner-friendly command-line expense tracker built with Python. It helps users record expenses, manage a monthly budget, and save their records between sessions.

## Features

- Add and view expenses
- Automatically record the expense date
- Calculate total expenses
- Set a monthly budget
- View the remaining budget
- Get a warning when expenses exceed the budget
- Delete an expense
- Save and load records using JSON
- Validate expense amount input

## Technologies

- Python
- JSON
- Python modules and functions

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

The application saves expense and budget data in a JSON file.
